## Enjoy Sports - Find-S and Candidate Elimination

## Dataset

The Enjoy Sports dataset is used to implement and study the Find-S and Candidate Elimination algorithms for concept learning.

## Objective

To implement Find-S and Candidate Elimination Algorithms on the Enjoy Sports dataset and compare the generated hypotheses.

## Steps Performed

1. Loaded the Enjoy Sports dataset using Pandas.
2. Separated the input attributes and target class.
3. Implemented the Find-S algorithm.
4. Trained the Find-S algorithm using the positive examples.
5. Obtained the final hypothesis using Find-S.
6. Implemented the Candidate Elimination algorithm.
7. Maintained the Specific (S) and General (G) hypotheses.
8. Updated the hypotheses for positive and negative examples.
9. Obtained the final Specific and General boundaries.
10. Compared the hypotheses generated by both algorithms.
