## Wine Quality Red - Decision Tree Classification

## Dataset

The **winequality-red.xls** dataset is used to implement and study the Decision Tree Classification algorithm. The dataset contains different physicochemical properties of red wine along with its quality class.

## Objective

To implement the Decision Tree Classification algorithm on the Wine Quality Red dataset and evaluate the classification performance of the model.

## Steps Performed

1. Loaded the Wine Quality Red dataset using Pandas.
2. Separated the input features and target class.
3. Preprocessed the dataset wherever required.
4. Split the dataset into training and testing sets.
5. Created a Decision Tree Classifier.
6. Trained the Decision Tree model using the training data.
7. Predicted the class labels for the test data.
8. Evaluated the model using accuracy.
9. Generated the confusion matrix to analyze the classification results.
10. Visualized the Decision Tree to understand the classification process.

## Tools Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Jupyter Notebook

## Model Evaluation

### Decision Tree Classifier

The Decision Tree Classifier is trained on the **winequality-red.xls** dataset and used to predict the quality class of the test data.

### Accuracy

The accuracy score is calculated by comparing the predicted quality classes with the actual quality classes in the test dataset.

### Confusion Matrix

The confusion matrix is used to analyze the correct and incorrect classifications made by the Decision Tree model.

## Output

The Decision Tree Classification algorithm successfully classifies the wine quality data. The model evaluation results and Decision Tree visualization are included in the Jupyter Notebook.

## Conclusion

The Decision Tree Classification algorithm was successfully implemented on the **Wine Quality Red dataset**. The model learned decision rules from the training data and classified the wine samples according to their quality. The performance of the model was evaluated using accuracy and a confusion matrix.
